# BATERDENE.EXE

Б.Бат-Эрдэнийн interactive 3D portfolio — mobile-first.

- `index.html` — 3D ертөнц (Three.js, build хэрэггүй, static)
- `classic.html` — хуучин энгийн хувилбар
- `js/data.js` — **бүх текст, төсөл, амжилт, нууц код энд** (засах бол зөвхөн энийг)
- `js/world.js` — 3D scene (бөмбөрцөг, гаригууд, төслийн тойрог, портал)
- `js/app.js` — boot, scroll→камер, дуу (WebAudio), нууц хэсэг
- `css/world.css` — загвар

Локалаар ажиллуулах (ES module тул file:// дээр ажиллахгүй):

```
python -m http.server 5180
# http://localhost:5180
```

3D/4D: scroll хийхэд камер 10 бүлгээр нисэж (hyperspace warp), хүрэлт бүр орон зайг долгилгоно, аялал урагшлах тусам ертөнцийн өнгө өөрчлөгдөнө. Объект бүр (бөмбөрцгийн үгс, гаригууд, үнэт зүйлс, төслийн картууд) дээр дарахад тайлбар нээгдэнэ. MN/EN хэлтэй.

Нууц: 4 ◆ хэлтэрхий олж, 07 · UNKNOWN хэсэгт код оруулна. Desktop дээр `bbe` гэж бичвэл хэлтэрхийнүүд гэрэлтэнэ.
